# Kirara_Server_APP

> 一款基于 WinUI 3 的 Windows 桌面客户端，用于统一使用与管理 Kirara_Server 上的各类应用服务。
> 通过 **新建实例 → 选择方案 → 链接令牌** 三步模型，实现一次配置、多服务直达、自动认证登录。

## ✨ 功能特性

- 📜 **软件许可协议拦截**：创建用户/服务实例前须阅读并同意《Kirara Server 软件许可协议》，同意状态按登录账户记录在本机；无人值守的实例自启同样受此闸门约束——未同意时**一颗实例都不会启动**，软件会先把窗口带回屏前弹出协议并等待，同意后**原地续跑**启动序列（无需重新登录）；「设置中心 → 协议管理」可随时撤回（撤回后立即关闭软件）
- 🗂️ **实例化管理**：区分用户实例与服务实例，支持重命名、收藏、颜色标签、导入/导出，多实例灵活切换；左侧栏实例标签行内提供一键「关闭实例」（忙态 / 未启动自动灰化，与首页「我的应用」卡片同源联动、状态实时同步）
- ☁️ **云同步（仅实例与令牌）**：左侧功能栏与令牌管理器的云朵入口提供「同步到云端 / 从云端恢复」；同步范围严格限定**实例 + 令牌**，软件设置偏好（主题 / 软件行为 / 左侧栏）与通知中心服务项**不参与**云同步，即使恢复历史版本上传的全量包也**不会覆盖**本机设置与通知已读状态；恢复计数按类别拆分（已恢复 / 本地已存在已跳过），云端数据可在「设置中心 → 数据管理 → 清空云端数据」一键删除
- 🧩 **插件化方案体系**：20+ 内置方案，覆盖媒体、直播、云盘、邮件、团队协作、虚拟化、远程桌面、OpenVPN、证书签发、游戏服务器等场景；亦支持导入第三方可执行文件作为方案
- 🛒 **应用商店**：左侧导航区最上方入口，浏览 / 搜索 / 下载生态可分发资源（Kirara 应用 / 插件 / 三方应用）；类型筛选 + 关键词模糊搜索，卡片式展示封面、描述与类型/版本徽章；封面准备门控，在途任务复用，刷新失败保留旧缓存；下载进度实时反馈并与下载管理器联动，下载按钮支持「下载 / 等待前序列任务完成... / 已安装此插件」三态
- 📦 **插件安装 / 卸载**：FreeRDP、OpenVPN、WebView2 三大运行时组件可在应用商店内一键安装/升级；自动就绪探测（未安装 / 已安装 / 版本过期），提权安装采用“证据优先”判据（以组件落地为准，不信退出码），WebView2 安装免提权；卸载仅限商店自装组件（系统级 WebView2 不提供卸载），OpenVPN 卸载前需断开连接，FreeRDP 目录被占用时拒绝卸载；卸载入口「可见 / 可用」分离，路径安全限制在 `ThirdAPPs` 目录下；安装/卸载后台执行可离开页面，重进页面自动恢复忙态
- 🖼️ **商店封面缓存**：封面经 `302` 预签名直链获取，ETag 比对 + AES-256-GCM 加密缓存（账号隔离）；同 Key 在途任务复用，门控可等待本次同步最终结果；商店来源通知可联动显示封面，未命中缓存时后台同步补显示
- 🧰 **商店 UI 体验加固**：卡片安装/下载/卸载忙态与悬停提示、卸载入口「可见 / 可用」分离、后台操作态恢复、统一结果弹窗（通知 / 警告）画刷回退与窗口主题跟随
- 🔗 **三方组件可选安装衔接**：安装器将 OpenVPN / FreeRDP 改为可选组件，默认不勾选；升级/静默安装继承本机已有安装情况；未装可从应用商店补装
- 🔑 **令牌管理器**：集中管理账户与证书，敏感字段经 **DPAPI + AES-256-GCM 双重加密**后落盘；支持手动导出/导入，也支持**扫码导出**——一键弹出动态加密二维码，供手机端扫码导入
- 📲 **扫码导出令牌**：令牌管理器每行附带扫码按钮，弹出动态二维码，手机 Kirara_Media 客户端扫码即可安全导入；二维码每 15 秒自动刷新、会话临近过期自动续期、全程 **AES-256-GCM 加密传输**，仅令牌所属账户可导入，非本人扫码会被拒绝并弹出安全提示
- 🔐 **自动登录引擎**：基于 WebView2 的自动化登录框架，内置多种方案适配，支持单步/分步/延迟登录与失败降级检测
- 🛡️ **自研 OpenVPN 管理面板**：集成 openvpn.exe 引擎，实时状态、流量、日志展示，.ovpn 配置由服务端统一同步分发
- 🖲️ **远程桌面输入体验加固**：FreeRDP / RDP 内嵌方案下**静默宿主机输入法**（抑制本地东亚候选框与吞键，按线程/窗口判断，仅切换输入模式不改语言），并在不抢焦点的前提下桥接剪贴板——后台复制不再强行激活宿主窗口或把窗口置顶
- 🔔 **实时通知中心**：SignalR WebSocket 实时推送 + 断线离线补拉 + 已读回执，通知带有信息流卡片轮播（图片/视频/HTML）；点赞、回复、催更等互动通知实时送达
- 💬 **议题评论系统**：方案页内嵌评论区，支持回复、点赞，多端同步；已扩展为「社区 / 我的最近评论 / 收藏 / 催更」四 Tab 视图
- ⭐ **收藏系统**：媒体评论面板一键收藏/取消，状态实时同步；「我的收藏」集中管理并一键回跳资源页
- 📣 **社区催更平台**：选择目标媒体库发布催更、点赞互动，管理员已读反馈实时推送
- 🎮 **游戏资源多版本下载**：游戏服务器资源平台内同一资源支持**多版本并行展示**（按版本号新→旧独立成行），版本级 SHA-256 完整性校验，下载进度实时反馈、完成后可一键打开文件夹
- 🌈 **外观主题系统**：跟随系统 / 手动明暗 / 48 色 Win11 风格主题色，三级联动即时生效；评论头像随明暗主题自动刷新适配

- 🖱️ **外部文件拖放接入**：可直接从资源管理器 / 桌面把文件拖入方案页、应用内独立浏览器窗口与汇聚管理平台（修复 WinUI 3 WebView2 无窗口承载下外部拖放被软件拦截、光标显示禁止符号的问题）；放行后由系统原生转交页面，页面拿到**真实文件条目**，页内自绘拖放高亮与上传控件全部照常生效
- ⏻ **开机自启双通道注册**：开启「开机自启」后同时写入注册表启动项与「登录时」计划任务，两条通道互为兜底——任一条被清理工具删除或被任务管理器禁用，另一条仍能把软件拉起；开关状态以应用内设置为唯一事实源，开启时自动修复被系统/优化工具标记为「已禁用」的启动项；自启链路的重复拉起为静默空操作，不会把已最小化或托盘中的窗口拽出来
- 🧹 **「清空数据」彻底回到全新安装**：除账号数据与缓存外，一并清理更新安装包目录、登录页记住的账号下拉与预填凭据、以及本版本注册的开机自启项；清理后登录页账号列表为空，不会残留「设置里已关、系统仍自启」的状态；与另一构建（开发版/正式版）共存时只清理属于本版本的自启注册，不会误删对方

- 🚪 **登出多端隔离**：登出时显式携带设备标识，服务端只吊销**本设备**的令牌，不再连带吊销同一账号在手机端或另一构建上的自动登录凭据

- 🔒 **OpenVPN 跨实例断开保护**：同时运行开发版与正式版时，任一方退出不再掐断另一方正在使用的 VPN 连接；连接进程意外退出后按指数退避自动重连（用户主动断开则不重连）
- 🖥️ **沉浸式界面**：Fluent 2 设计语言、自绘标题栏、DPI 自适应（PerMonitorV2）、全局忙状态遮罩与页面转场动画

## ⬇️ 安装与更新

1. 前往本仓库 **Releases** 页面下载最新安装包（`Kirara_Server_APP_Setup_x64_vX.X.X.exe`）
2. 运行安装程序，按向导完成安装
3. 首次启动后注册/登录 Kirara_Server 通行证，即可开始创建你的第一个实例
4. 程序有自动更新程序，可以实现自动卸载旧版本安装更新
5. WebView2 为必需组件；OpenVPN / FreeRDP 为可选组件，安装时默认不勾选，未勾选也可在应用内「**应用商店**」随时补装或升级

7. 首次创建用户/服务实例前需阅读并同意《Kirara Server 软件许可协议》，同意状态按账户记录在本机，可在「设置中心 → 协议管理」撤回

## 🚀 快速开始

### 三步上手

```
① 新建实例  →  ② 选择方案（可多选）  →  ③ 链接令牌
```

1. **新建实例**：在左侧功能栏点击「创建新用户实例」或「创建新服务实例」，命名并选择方案
2. **链接令牌**：为每个方案链接对应的账户令牌（在令牌管理器中预先创建）
3. **一键直达**：应用实例后，程序自动与服务端协商通信方式、自动填充凭据并尝试登录，成功后即可在标签页中直接使用各方案服务

> 💡 也可以使用「快速开始」模板，直接套用官方配置好的常用服务组，省去手动配置。

### 常用操作

- **实例管理**：主界面左栏集中管理；实例支持导入/导出 `.kirara` 文件分享；实例标签行内「关闭实例」一键关闭（忙态 / 未启动自动灰化）
- **云同步**：左侧功能栏搜索框右侧的云朵按钮（令牌管理器内也有一枚）→「同步到云端 / 从云端恢复」，**只同步实例与令牌**；云端数据可在「设置中心 → 数据管理 → 清空云端数据」删除
- **许可协议**：首次创建实例时需阅读并同意；「设置中心 → 协议管理」可撤回已同意的协议（未同意时按钮灰化）
- **外部拖放**：从资源管理器 / 桌面把文件直接拖到方案页、独立浏览器窗口或汇聚管理平台即可上传，无需先复制粘贴
- **令牌管理**：创建/编辑/删除令牌，支持批量导出与导入；令牌关联的应用凭据全程加密存储
- **扫码导出令牌**：在令牌管理器点令牌行右侧的「扫码」按钮，弹出动态二维码——用手机 Kirara_Media 客户端的「扫码导入」对准扫描即可自动完成导入（手机与电脑需登录同一账户）
- **应用商店**：左侧导航区最上方「应用商店」入口，浏览/搜索生态资源，下载安装插件（FreeRDP / OpenVPN / WebView2），已装插件可一键卸载；下载按钮支持「下载 / 等待前序列任务完成... / 已安装此插件」三态
- **插件卸载**：插件卡片常显卸载图标，仅商店自装组件可用；WebView2 不提供卸载，OpenVPN 卸载前需断开连接，FreeRDP 目录被占用时会提示先关闭相关程序
- **方案操作**：标签页内可刷新（保留会话）、硬重载（清除 Cookie/缓存）、重新链接令牌
- **通知中心**：右下角角标展开，包含「信息流 / 服务项 / 日志项」三个标签页
- **外观设置**：设置页可切换明暗主题与主题色，支持跟随系统

核心设计：

- **插件式方案**：`IScheme` 接口 + 编译期安全的 Guid→Type 映射，支持 WebView2 / RDP / CustomControl / Overlay / ExternalProcess 五种呈现方式
- **远程服务替换式接入**：所有远程服务（认证、通知、评论、模板、信息流等）均实现既有接口，通过 DI 替换注册即可接入，离线时自动降级
- **增量同步**：方案 URL、信息流卡片、.ovpn 配置均采用版本号 + 客户端上报的增量同步，网络开销极小
- **凭据安全**：RefreshToken 等敏感凭据仅以 DPAPI + AES-256-GCM 加密形式落盘，AccessToken 仅存内存并在过期前自动刷新
- **扫码导出安全**：二维码经服务端一次性会话换钥 + AES-256-GCM 加密，每帧随机 nonce；即使二维码被截屏，非属主账户也无法解密导入
- **商店插件链路**：商店资源与游戏资源平台共用 `GET /api/downloads`（`store` 首段命名空间隔离，互不串扰）；封面 `302` 预签名直链 + ETag 比对 + 账号隔离 AES-256-GCM 加密缓存，在途任务复用，封面准备门控；插件安装采用提权 + 证据优先判据（以组件落地为准，不信退出码），WebView2 安装免提权；卸载仅限商店自装组件（`IsAppOwned`），单次 UAC 内完成停本程序进程 / `msiexec /x` / 删除目录，路径安全限制在 `ThirdAPPs` 目录下
- **三方组件可选安装衔接**：安装器与商店插件指向同一份 `{app}\ThirdAPPs\{插件}`，未装可从商店补装，升级继承已有安装情况
- **云同步包边界**：`ExportCloudSyncBundle` / `ImportCloudSyncBundle` 只搬「实例 + 令牌」，与设置中心 v2 全量包（实例 + 令牌 + 设置偏好 + 通知）共用同一套导入核心但语义分离；实例包内即使残留历史版本上传的设置/通知字段也一律忽略；默认令牌只合并 ApiKey / ServerUrl（账密永不覆盖，避免顶掉本机自动登录），明文无变化时不重新加密落库 —— 因此「上传后立即恢复」不会改动本地密文
- **许可协议闸门**：`LicenseAgreementService` 按账户持久化同意状态（`license.agreed.{userId}`），并提供「授予事件 + 轮询」双保险的等待语义。用户主动点击入口只拦截不等待（「查看许可协议」≠ 同意）；无人值守自启走「拦截 + 等待」，静默启动（窗口屏外停放）时先把窗口恢复到屏前再弹窗，同意后原地续跑，拒绝 / 超时则放弃本次自启
- **WebView2 外部拖放**：WinUI 3 的 WebView2 为无窗口（visual hosting）承载，拖放命中测试落在 XAML 岛 —— 必须由 XAML 层显式 `AllowDrop=true` 且在 `DragOver` 中给出 `AcceptedOperation=Copy`（仅文件类）才放行；放行后由 WinUI 原生把 drop 转交 Chromium 页内，宿主无需自读文件代传（避免与原生转发形成双路径重复上传）；`WebView2ExternalDropBridge` 幂等挂接（弱引用表）并在控件自愈重建后重新挂接

## ❓ 常见问题

<details>
<summary><b>手机扫码导入失败 / 提示拒绝？</b></summary>

手机扫码导入时，手机上登录的 KIRARA 账户必须与桌面端导出令牌的账户一致——令牌只能导入到其所属账户。另外二维码约每 15 秒刷新一次，若提示「二维码已过期」，请等桌面端图案刷新后立即重扫，并保持桌面端扫码窗口打开。
</details>

<details>
<summary><b>提示「需要管理员权限」？</b></summary>

应用本体以普通用户权限运行（`asInvoker`，v0.9.1+），OpenVPN 所需的虚拟网卡由安装时注册的 `KiraraVpnHelper` 服务（LocalSystem）代理创建，**连接 VPN 不需要 UAC 提权**。只有安装 / 升级 / 卸载安装包本身需要管理员权限，请右键安装包选择「以管理员身份运行」。
</details>

<details>
<summary><b>云同步会上传我的设置与通知吗？</b></summary>

不会。云同步只搬运「实例 + 令牌」：软件设置偏好（主题 / 软件行为 / 左侧栏）与通知中心服务项都不参与同步；从云端恢复时，即使包内带有这些字段（历史版本上传的全量包）也会被忽略，不会覆盖本机设置与通知已读状态。云端已存的数据可在「设置中心 → 数据管理 → 清空云端数据」删除。
</details>

<details>
<summary><b>提示「软件许可协议未生效」，实例没有自动启动？</b></summary>

未同意《Kirara Server 软件许可协议》时，所有实例都不会启动：创建 / 打开实例会先弹出协议对话；无人值守的实例自启（含静默启动）会把窗口带回屏前后弹窗等待，同意即**原地继续启动**，拒绝或超时则放弃本次自启。查看与撤回入口在「设置中心 → 协议管理」。
</details>

<details>
<summary><b>能从资源管理器直接拖文件进页面吗？</b></summary>

可以。方案页、应用内独立浏览器窗口与汇聚管理平台都支持从资源管理器 / 桌面拖入文件（拖入时光标显示「复制」，页内拖放高亮与上传控件照常生效）。若某个页面拖入后上传无反应，请把该方案页地址反馈给我们，以便补充页内转发。
</details>

<details>
<summary><b>OpenVPN / FreeRDP 未安装或版本过旧？</b></summary>

打开应用内「应用商店」，搜索对应插件一键安装/升级即可；商店会自动探测本机组件状态（未安装 / 已安装 / 版本过期），无需手动下载安装包。WebView2 为系统级组件，不提供卸载；OpenVPN 卸载前需先断开连接；FreeRDP 卸载时若目录被占用，请先关闭相关程序。
</details>

<details>
<summary><b>商店封面没有立即显示？</b></summary>

封面首次使用会经 `302` 预签名直链下载并写入账号隔离加密缓存；若未命中缓存，商店会先显示类型图标并在后台同步，完成后自动刷新。刷新失败时会保留旧缓存，不会闪空。
</details>

<details>
<summary><b>网络异常时还能使用吗？</b></summary>

应用支持离线降级：本地缓存、本地认证与本地评论可作为兜底；联网后自动恢复远程同步与实时推送。
</details>

<details>
<summary><b>令牌/实例数据存在哪里？</b></summary>

数据保存在 `%APPDATA%/Kirara/` 目录下，令牌等敏感字段均已加密，请勿直接拷贝该目录给他人。v1.5.0 起数据按账号隔离存储（`users/{账号ID}/` 子目录 + 全局层），切换账号互不可见。如果软件的数据出现异常，可先在「设置中心 → 数据管理」尝试「清空缓存」（仅删方案缓存，账号数据不受影响）或「清空本地数据」（删除账户数据、全部本地缓存、**登录页记住的账号**与开机自启项，不可撤销，请先导出备份），仍未解决再卸载重装。
</details>
